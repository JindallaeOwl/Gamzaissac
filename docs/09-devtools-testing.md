## 개발자 콘솔

게임 중에 열고, **비밀번호 인증 후** 명령을 실행합니다.

> 비밀번호 원문, 해시 생성 과정, 비밀 입력 순서는 **문서·커밋 메시지에 적지
> 않습니다.** 필요하면 구현 코드를 직접 확인합니다.

### 명령 목록

| 명령                | 하는 일                                |
| ------------------- | -------------------------------------- |
| `help`              | 명령어 목록                            |
| `god`               | 무적 켜기/끄기                         |
| `heal`              | 체력 완전 회복                         |
| `items`             | 아이템 번호와 ID 목록                  |

| `boss`              | 현재 층의 보스방으로 이동              |
| `shop`              | 현재 층의 상점방으로 이동              |
| `treasure`          | 현재 층의 보물방으로 이동              |
| `spawn 013`         | 아이템 번호로 생성                     |
| `spawn prism-lance` | 영문 ID로 아이템 생성                  |

| `floor 2`           | 지정한 층으로 이동 (1~8)               |
| `clear`             | 콘솔 출력 지우기                       |

### 설계 메모

- **콘솔로 부른 적도 자연 배치된 적과 똑같이 동작합니다.** 생성이
  `RoomController.spawnDeveloperEnemy` → 기존 `registerSpawnedEnemy` 경로를 그대로
  타기 때문입니다
- 콘솔 스폰은 플레이어 옆 약 90px 떨어진 곳에 놓습니다 — 머리 위에 놓으면 대개
  테스트하려던 "접근 과정"을 건너뛰게 됩니다
- `floor` 명령은 1~8만 허용합니다 (존재하지 않는 층으로 가면 진행 판정이 깨짐)

### `ADMIN` 표시

실제 게임 상태를 바꾸는 관리자 명령을 쓰면 화면에 `ADMIN`이 뜨고, 그 런은
`runState.adminUsed = true`가 되어 **랭킹 등록 대상에서 제외**됩니다.
(랭킹 API 연동 자체는 아직 없고, 자격 판정 함수만 준비되어 있습니다.)

## 아이템 선택기 (`F2`)

콘솔 인증 후 `F2`로 열고 닫습니다. 아이콘 그림과 `ID: 001` 형식의 번호, 이름을
함께 보여 줘서 번호를 외울 필요가 없습니다. 창 위치와 크기는 브라우저에 저장됩니다.

## 코나미 코드

`↑ ↑ ↓ ↓ ← → ← → B A` 를 입력하면 프리즘 창과 쿼드샷이 플레이어 옆에 생깁니다
(시너지 확인용). 방 안쪽으로 위치가 보정됩니다.

## 알려진 함정 (중요)

1. **`npm run check`가 가끔 전 테스트 파일을 `reading 'config'` 오류로 실패시킵니다.
   다시 실행하면 통과합니다.** 진짜 회귀로 오판하지 마세요
2. **모션·연출 작업은 AI가 결과를 볼 수 없습니다.** 레퍼런스(영상·이미지) 없이
   말로만 왕복하면 실패합니다 — 퇴장 연출을 5회 왕복하다 취소한 사례가 있습니다.
   레퍼런스를 주고, 프레임을 추출해 분석한 뒤 구현합니다
3. **픽셀 그림·아이콘은 구현 후 반드시 PNG로 렌더링해 눈으로 확인합니다.**
   격자 문자열은 행 길이와 좌우 대칭을 프로그램으로 검사합니다
4. 빌드의 "500kB 이상 번들" 경고는 빌드를 막지 않는 안내입니다

## 테스트 작성 방침

새 규칙을 만들 때 **순수 함수**(`~Rules.ts`)로 떼어 내면 테스트를 붙일 수 있습니다.
지금까지 이 방식으로 고정한 것들:

- 던전 생성·방 템플릿 선택·문간 기하
- 아이템 능력치 적용·중첩·드랍 풀
- 보상 추첨 구간·상자 결과
- 적 증원·소환 상한·챔피언 추첨·보스 패턴 수치 관계
- 입력 스냅샷·터치 스틱·설정 순환
- 폭탄·상자 밀기 수치

랜덤이 들어가는 곳은 **난수원을 주입 가능하게** 만들어(`RandomSource`) 테스트에서
결과를 재현합니다.
