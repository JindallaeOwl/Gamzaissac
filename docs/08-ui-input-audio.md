## 화면 구성 (Scene)

| Scene                  | 역할                                 |
| ---------------------- | ------------------------------------ |
| `BootScene`            | 에셋 로딩, 도트 텍스처 생성          |
| `TitleScene`           | 타이틀 + 메인메뉴 + 설정             |
| `TitleTransitionScene` | 타이틀 ↔ 게임 사이 전환 연출 (280ms) |
| `GameScene`            | 실제 플레이 전부                     |
| `PauseScene`           | 일시정지 + 설정 + 나가기             |

## 조작 — 키보드

| 조작                      | 키                   |
| ------------------------- | -------------------- |
| 이동                      | `W` `A` `S` `D`      |
| 씨앗 발사 / 빔 차징       | 방향키               |
| 폭탄 설치                 | `E`                  |
| 상점 구매 / 씨눈 심기     | `F`                  |
| 미니맵 확대               | `Tab` (누르는 동안)  |
| 미니맵 확대 고정/해제     | `Tab` 짧게 누르기    |
| 일시정지 / 설정           | `Esc`                |
| 언어 전환                 | `L`                  |
| 디버그 표시               | `F3`                 |
| 개발자 아이템 선택기      | `F2` (콘솔 인증 후)  |
| 결과 화면에서 타이틀 복귀 | `Enter` 또는 `Space` |

메뉴 조작: 위/아래 방향키 또는 `W`/`S`, 실행은 `Enter`/`Space`, 마우스 hover·click도 지원.

> `F`가 상점 구매와 씨눈 심기에 함께 쓰이지만, 서로 다른 방에서만 성립해 겹치지 않습니다.

## 조작 — 모바일 터치

터치 지원 기기에서 **가로 화면**일 때 자동으로 나타납니다. 세로일 때는 회전 안내를 표시합니다.

| 위치             | 기능                                      |
| ---------------- | ----------------------------------------- |
| 왼쪽 스틱        | 8방향 이동                                |
| 오른쪽 스틱      | 4방향 사격 · 차징 빔                      |
| 오른쪽 버튼      | 폭탄 / 상품 근처에서만 나타나는 구매 버튼 |
| 오른쪽 위 버튼   | 일시정지                                  |
| 미니맵 직접 터치 | 확대 고정/해제                            |

### 입력이 하나로 합쳐지는 구조

키보드든 터치든 **불리언 8개짜리 스냅샷**(`PlayerControls`)으로 바뀐 뒤 OR로 합쳐집니다
(`mergeControls`). 그래서 한쪽 입력이 다른 쪽을 지우지 않고, 나중에 게임패드를 붙일
때도 같은 자리에 끼우면 됩니다.

오프닝·일시정지·런 종료·씬 종료 때는 입력을 초기화합니다 (키가 눌린 채 남는 것 방지).

## 오디오

### 배경음악 4곡

| 상황    | 곡                |
| ------- | ----------------- |
| 타이틀  | `start.ogg`       |
| 일반 방 | `journey.ogg`     |
| 상점    | `shop.ogg`        |
| 보스방  | `boss-battle.ogg` |

방을 옮기면 크로스페이드(들어옴 420ms / 나감 260ms)로 자연스럽게 바뀝니다.
음악 상태는 Phaser 레지스트리에 보관해 **씬이 바뀌어도 끊기지 않습니다.**
`pauseOnBlur = false`라 브라우저 탭을 벗어나도 계속 재생됩니다.

### 효과음 🟡

WebAudio 오실레이터로 **합성해서 만드는 소리**입니다 (음원 파일 없음).
`AudioSystem`이 실패해도 게임 루프가 멈추지 않도록 예외를 삼킵니다.
실제 음원 교체는 아직 계획 단계입니다.

### 화면 흔들림 (`FEEDBACK_TUNING.cameraShake`)

상황마다 세기와 길이가 다릅니다. 설정의 "화면 흔들림" 값이 여기에 곱해집니다.

| 상황          | 길이 / 세기    |
| ------------- | -------------- |
| 탄환 명중     | 42ms / 0.0014  |
| 빔 발사       | 90ms / 0.0022  |
| 적 사망       | 95ms / 0.0035  |
| 플레이어 피격 | 130ms / 0.006  |
| 문 닫힘       | 110ms / 0.0032 |
| 방 클리어     | 130ms / 0.0024 |
| 보스 2페이즈  | 230ms / 0.007  |
| 폭탄 폭발     | 200ms / 0.0065 |

> **히트스톱은 물리 월드를 멈추지 않습니다.** 짧은 카메라 플래시만 씁니다 —
> `pause`나 `timeScale`을 건드리면 다른 타이머가 어긋납니다.
