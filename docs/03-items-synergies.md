# 03. 아이템과 시너지

> 상태: ✅ 완료 · 마지막 코드 대조 2026-09-01

## 아이템 분류 체계

| 구분      | 값                                                                   |
| --------- | -------------------------------------------------------------------- |
| 희귀도    | `common` / `uncommon` / `rare` / `legendary`                         |
| 분류      | `offense`(주홍) / `defense`(초록) / `utility`(하늘) / `resource`(금) |
| 드랍 출처 | `combat` / `shop` / `treasure` / `boss` (여러 개 가능)               |
| 최대 중첩 | 1이면 유일, 2 이상이면 그만큼 겹쳐 먹을 수 있음                      |

## 드랍 테이블 (`ITEM_DROP_TABLES`)

| 출처   | 드랍 확률 | common | uncommon | rare | legendary |
| ------ | --------: | -----: | -------: | ---: | --------: |
| 전투방 |    **7%** |     64 |       28 |    7 |         1 |
| 상점   |      100% |     52 |       36 |   12 |         0 |
| 보물방 |      100% |      0 |       48 |   37 |        15 |
| 보스방 |      100% |     30 |       35 |   35 |         0 |

- 전투방 드랍 확률은 행운 1당 +1%, **상한 14%**입니다
- **전투방과 보스방은 "순수 능력치형"만 나옵니다** — 공격 거동을 바꾸는 아이템
  (쿼드샷·물결 등)과 능력 해금 아이템은 자동 제외됩니다 (`isStatOnlyItem`)
- 거동 아이템은 보물방·상점처럼 **기대하고 여는 자리**의 몫입니다

### 보스 보상 풀 (`BOSS_REWARD_ITEM_IDS`, 12종)

`red-mushroom`, `pulse-relay`, `glass-fern`, `feather-coil`, `hot-pebble`,
`steady-pin`, `moon-dial`, `long-echo`, `amber-heart`, `star-fertilizer`,
`spike-rind`, `deep-root`

> **보스 보상을 추가하려면**: ① `src/data/items.ts`에 아이템 추가 → ② `dropSources`에
> `'boss'` 포함 → ③ `src/data/bossRewards.ts`의 목록에 ID 추가. 순수 능력치형이
> 아니면 실수로 넣어도 자동 제외됩니다.

## 시너지 6종 (`ITEM_SYNERGIES`)

두 아이템을 모두 가지면 **한 번만** 발동하고, 발동 사실이 화면에 알림으로 뜹니다.

| 시너지      | 필요 아이템                   | 효과                                    |
| ----------- | ----------------------------- | --------------------------------------- |
| 프리즘 배열 | 쿼드샷 + 프리즘 창            | 빔 차징 시간 30% 단축                   |
| 유리 지평선 | 유리 고사리 + 긴 메아리       | 공격력 +0.55, 사거리 +45                |
| 조율된 회로 | 펄스 중계기 + 안정 핀         | 공속 +0.4, 씨앗 속도 +30                |
| 예비 껍데기 | 주머니 배터리 + 나무껍질 조끼 | 최대 체력 +2, 2 회복                    |
| 복리 행운   | 클로버 새싹 + 행운 장부       | 행운 +2                                 |
| 운석 씨앗   | 뜨거운 조약돌 + 메가씨드      | 공격력 +0.75, 씨앗 속도 +60, 크기 ×1.15 |

발동 안내는 `applyPassiveAcquisition` **한 곳**에서 배선되어 있어, 줍기·구매·앞으로
생길 어떤 획득 경로든 시너지 알림을 빠뜨릴 수 없습니다. 연출과 효과음은 알림이
**실제로 화면에 나타나는 순간**(`onShow` 콜백) 재생됩니다 — 즉시 재생하면 줍기 연출에
묻히기 때문입니다.

## 아이템 추가 원칙 (2026-08-17 확정 — 반드시 지킬 것)

새 아이템을 만들 때 이 규칙을 지키면 조합이 저절로 늘어납니다.

1. **새 거동은 반드시 공격 프로필(`PlayerAttackProfile`)의 속성으로 만든다.**
   씬이나 시스템 코드에서 아이템 ID로 `if` 분기하지 않습니다 — 프리즘 배열이 처음에
   그렇게 만들어졌다가 검수에서 고쳐진 사례가 있습니다
2. **각 속성은 "직전 단계의 전체 결과"에 적용되게 설계한다.** 뒷발사는 앞 부채꼴
   전체의 거울, 점사는 볼리 전체의 반복, 물결은 모든 씨앗의 궤적 — 이렇게 만들면
   새 속성 하나가 기존 전부와 자동으로 곱해집니다
3. **씨앗 발사는 `Player.spawnSeedFan` 한 경로만 쓴다.** 별도 `Bullet.spawn` 지점을
   만들면 그 거동부터 조합이 깨집니다
4. **단일 아이템 화력 상한은 2배.** 어떤 아이템도 혼자서 초당 화력을 2배 넘게 올리지
   않습니다. 특히 곱셈 배율(`damageMultiplier`)은 다른 곱셈과 만나 폭발하므로 아껴
   씁니다 — 메가씨드가 ×2로 단독 4.2배가 되어 런 전체를 망가뜨렸던 사례가 있습니다
5. **이름만 있고 효과가 없는 아이템은 테스트가 잡는다.**
   `tests/attack-profile-consumption.test.ts`(전투 코드가 속성을 읽는지)와
   `tests/items.test.ts`(`attackModifiers`가 프로필을 실제로 바꾸는지)

## 알려진 한계 · 다음 후보

- 액티브(사용하는) 아이템과 슬롯은 없습니다. 다만 `itemNumber`는 패시브·액티브가
  같이 쓰도록 설계해 두어 나중에 이어 붙일 수 있습니다
- 시너지는 **고정 조합표**라 6종에서 늘리려면 손으로 적어야 합니다. 방향은 조합표를
  늘리는 것이 아니라 **공격 프로필 축을 늘려 조합이 저절로 생기게 하는 것**입니다
