# 07. 진행과 스테이지

> 상태: 🟡 구조 완료 / 엔딩 연출 임시 · 마지막 코드 대조 2026-09-01

## 한 줄 요약

땅속에서 시작해 8층까지 올라가면 탈출입니다. 4개 스테이지가 각각 2층씩 차지하고,
각 층 끝에는 보스가 있습니다. 층을 오를 때마다 체력이 반 칸 회복됩니다.

## 스테이지 구성

| 스테이지 | 이름                       | 층    | I층 보스 (중간보스) | II층 보스 (스테이지 보스) |
| -------: | -------------------------- | ----- | ------------------- | ------------------------- |
|        1 | 썩은 뿌리 (지하 깊은 곳)   | 1~2층 | 뿌리 옹이           | 썩은 뿌리핵               |
|        2 | 지렁이 소굴 (어두운 흙 속) | 3~4층 | 꿈틀대는 덩어리     | 늙은 지렁이 왕            |
|        3 | 퇴비더미 (김 나는)         | 5~6층 | 파리 여왕           | 퇴비 파수꾼               |
|        4 | 넝쿨 통로 (빛이 새는)      | 7~8층 | 가시넝쿨 뭉치       | **녹슨 쇠스랑의 농부**    |

스테이지 색조는 **전투방·시작방에만** 적용됩니다. 상점·보물·보스방은 기능을 알아보게
하려고 방 종류별 고유색을 유지합니다.

> 새 보스를 만들면 `src/data/stages.ts`의 해당 스테이지 `bossIds`만 바꾸면 됩니다.
> 보스방 템플릿은 스테이지 데이터에서 자동으로 파생됩니다.

## 한 판(런)의 흐름

1. 타이틀에서 시작 → 오프닝 연출
2. **시작방**에서 출발. 왼쪽 위에 씨눈 텃밭이 있음
3. 전투방·상점방·보물방을 돌며 아이템과 자원을 모음
4. **보스방**에서 그 층의 보스를 처치
5. 보상(순수 능력치형)과 함께 **위로 뚫린 굴**이 생김
6. 굴에 들어가면 다음 층 — 던전이 새로 생성되고 체력 반 칸 회복
7. 4~6을 반복해 8층까지
8. **8층 보스 처치 → 탈출구 → 탈출 성공 화면 → 타이틀 복귀**
9. 도중에 체력이 다 하면 게임오버 화면 → 타이틀 복귀

### 층 출구 판정 (`RunProgressionSystem.resolveFloorExit`)

| 상황           | 결과                                    |
| -------------- | --------------------------------------- |
| 런이 이미 끝남 | 무시 (아무것도 안 바꿈)                 |
| 층 값이 1~8 밖 | 오류를 던짐 (조용히 잘못 처리하지 않게) |
| 정확히 8층     | `outcome = 'escaped'` — 탈출 확정       |
| 1~7층          | 다음 층으로, 체력 +1 (반 칸)            |

> 일부러 `floor >= 8`이 아니라 `floor === 8`로 판정합니다. 그래야 개발자 콘솔로
> 이상한 층에 갔을 때도 잘못된 탈출 처리가 일어나지 않습니다.

## 씨눈 심기 (시작방 텃밭)

**런 안에 남는 투자**를 시험하는 장치입니다.

| 항목      | 내용                                                |
| --------- | --------------------------------------------------- |
| 위치      | 시작방 **왼쪽 위** (방 왼쪽에서 64, 위에서 56)      |
| 조작      | 반경 30px 안에서 `F`                                |
| 치르는 값 | **최대 체력 반 칸** (회복이 아니라 최대치가 줄어듦) |
| 받는 것   | **다음 층 시작방**에 아이템이 자라 있음             |
| 꽝        | 20% 확률로 동전 한 닢만 나옴                        |
| 제한      | 층당 1회. **8층에서는 불가** (수확할 층이 없음)     |
| 안전장치  | 반 칸을 내고도 최소 반 칸이 남아야 심을 수 있음     |

### 왜 이렇게 만들었나

보상이 **늦게** 온다는 점이 핵심입니다. "얼마나 강해지나"가 아니라 **"다음 층까지 이
몸으로 버틸 수 있나"**를 묻게 되어 망설임의 결이 달라집니다.
층당 한 번으로 묶은 이유는, 제한이 없으면 "체력 다 갈아넣기"가 최적해가 되어 망설임
자체가 사라지기 때문입니다.

> 수확 판정은 **방에 들어설 때마다** 확인합니다(`handleRoomEntered` 한 경로).
> 층 이동만 따로 처리했더니 개발자 콘솔 `floor` 명령으로 올라갔을 때 자라지 않았습니다.

> **사용자 방향 메모**: 거점(우리 집)에서 재료를 모아 발전시키는 게임에 끌린다는
> 이야기가 있었고, 씨눈 심기는 그 감각의 **런 안 축소판**입니다. 이게 재미있으면
> 거점으로 키우고, 아니면 크게 잃지 않고 접을 수 있습니다.

## 런 상태 (`RunState`)

한 판 동안 들고 다니는 정보 전부입니다.

| 필드                     | 무엇                                       |
| ------------------------ | ------------------------------------------ |
| `outcome`                | `playing` / `defeated` / `escaped`         |
| `floor`                  | 현재 층 (1~8)                              |
| `clearedRooms` / `score` | 클리어 방 수, 점수                         |
| `collectedItemIds`       | 획득한 아이템 (중첩은 같은 ID가 여러 번)   |
| `unlockedAbilityIds`     | 해금한 능력 (차징 빔 등)                   |
| `activatedSynergyIds`    | 이미 발동한 시너지                         |
| `inventory`              | 열쇠·폭탄·코인                             |
| `seedPlantedOnFloor`     | 씨눈을 심은 층                             |
| `stats`                  | 현재 능력치 전부                           |
| `attackProfile`          | 현재 공격 프로필                           |
| `adminUsed`              | 개발자 명령을 썼는가 (랭킹 등록 불가 표시) |

> `outcome`이 **패배·탈출 판정의 유일한 기준**입니다. 화면 쪽 상태
> (`gameOverStarted` 등)는 오버레이가 두 번 뜨는 것만 막습니다.

## 상태 유지 범위

### 한 판(런) 안에서 유지됨

- 현재 층, 점수, 클리어 방 수
- 체력과 능력치, 획득 아이템, 해금 능력, 발동 시너지
- 열쇠·폭탄·코인
- 방별 클리어 여부와 특수방 잠금 해제 여부
- 방에 남겨둔 아이템·보상의 종류·상태·위치
- 심어 둔 폭탄의 자리 (도화선은 재입장 때 새로 셈)
- 텃밭에 묻어 둔 씨눈 (심은 층을 기억)
- 상점 상품·구매 여부·할인 상태
- 보스 보상 선택 및 획득 여부

### 브라우저를 닫아도 유지됨

- 언어 설정
- 사운드·효과음 음량·화면 흔들림·렌더 품질
- 개발자 콘솔·아이템 선택기 창 위치와 크기

### 아직 유지되지 않음 ⛔

- **진행 중인 런 전체 저장/불러오기** — 브라우저를 닫으면 런은 사라집니다
- 최고 점수와 플레이 기록
- 외부 랭킹 등록 (`adminUsed`와 자격 판정 함수만 준비됨)
