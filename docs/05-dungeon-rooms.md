# 05. 던전과 방

> 상태: ✅ 완료 · 마지막 코드 대조 2026-09-01

## 한 줄 요약

층에 들어설 때마다 방들이 새로 배치됩니다. 방은 5종류이고, 전투방은 12개 템플릿 중
하나를 뽑아 씁니다. 방 안에서 일어난 일(줍지 않은 보상, 심은 폭탄, 부순 상자)은
방을 나갔다 돌아와도 그대로 남습니다.

## 지금 되는 것

- [x] 시작방은 실제 이동 가능한 출구를 최소 2개 보장
- [x] 층이 오를수록 전투방 수 증가
- [x] 전투방 템플릿 12종 × 배치 3벌 = 36조합, 층 게이팅 + 직전 중복 방지
- [x] 방 클리어 상태·발견 여부를 미니맵에 반영

- [x] 방을 나갔다 와도 상태 유지 (보상·아이템·폭탄·부순 상자·상점 재고)

## 방 5종류

| 종류     | 클리어 조건       | 특징                                     |
| -------- | ----------------- | ---------------------------------------- |
| start    | 처음부터 클리어됨 | 시작 지점. 왼쪽 위에 씨눈 텃밭이 있음    |
| combat   | 적 전멸           | 템플릿 12종 중 하나. 클리어 시 보상 추첨 |
| shop     | 처음부터 클리어됨 | 상인 + 상품 4개. 2층부터 열쇠 1개 필요   |
| treasure | 처음부터 클리어됨 | 중앙에 아이템 1개. 2층부터 열쇠 1개 필요 |
| boss     | 보스 처치         | 처치 시 보상 + 위로 뚫린 굴 생성         |

## 던전 생성 규칙 (DungeonManager.generateFloor)

방은 격자 좌표 위에 놓입니다. 순서가 정해져 있어 결과가 예측 가능합니다.

1. 시작방을 (0,0)에 놓고 클리어·발견 상태로 표시
2. 동쪽과 남쪽에 전투방을 하나씩 → **시작방 출구 2개 보장**
3. 추가 전투방을 동쪽 방부터 사슬처럼 이어 붙임
4. **보물방**은 남쪽 전투방에 붙임
5. **상점방**은 동쪽 전투방에 붙임
6. **보스방**은 마지막으로 이어 붙인 전투방에 붙임

### 층별 방 수

| 층    | 전투방 | 전체 방 수 |
| ----- | -----: | ---------: |
| 1층   |      3 |          7 |
| 2층   |      5 |          9 |
| 3~8층 |      6 |         10 |

```
전투방 수 = 1층이면 3, 아니면 min(6, 3 + 층)
```

### 특수방 잠금

1층에서는 상점방·보물방이 **열려 있습니다.** 2층부터 입장 시 열쇠 1개를 씁니다
(`INVENTORY_TUNING.specialRoomKeyCost`).

## 전투방 템플릿 12종

각 템플릿은 **적 배치 3벌**(spawnSets)을 갖고 있어 같은 템플릿이라도 다르게 보입니다.
12 × 3 = **36조합**. 이전에는 조합이 8개뿐이라 한 판에 같은 방을 평균 5.5회 만났고,
지금은 1.2회로 줄었습니다.

| 템플릿 ID      | 등장 층 | 상자 | 특징                                       |
| -------------- | ------: | ---: | ------------------------------------------ |
| split-lanes    |     1층 |    2 | 기본 배치                                  |
| burnt-cross    |     1층 |    2 | 십자 형태                                  |
| staggered-rail |     1층 |    2 | 위아래 갈림                                |
| low-orbit      |     1층 |    0 | 상자 없음, 넓게 둘러쌈                     |
| pillar-hall    |     1층 |    4 | 기둥 네 개                                 |
| corner-forts   |     1층 |    4 | 사수가 구석에 자리 잡음                    |
| broken-wall    |     2층 |    6 | 가운데 부서진 벽. 분열형 등장              |
| slant-ridge    |     2층 |    4 | 대각선 능선                                |
| choke-cross    |     3층 |    5 | 가운데 막힌 십자. **측면포위형 고정 배치** |
| flank-alley    |     3층 |    8 | 좁은 골목. 측면포위형 최대 2마리           |
| spore-garden   |     4층 |    4 | 분열형 다수                                |
| brood-nest     |     5층 |    2 | **소환형 고정 배치**                       |

### 템플릿 선택 규칙 (RoomTemplateRules)

- minFloor 이상인 템플릿만 후보가 됩니다 — 층이 오를수록 새 방이 풀립니다
- **직전에 뽑힌 템플릿은 제외**하고 뽑습니다 (같은 방 연속 등장 방지)
- 층을 새로 만들 때 "직전 기억"은 초기화됩니다

> **중요**: 층 제한이 있는 적(분열형 2층·측면포위 3층·소환 5층)을 고정 배치한 템플릿은
> 그 적의 등장 층 이상이어야 합니다. `tests/room-template-rules.test.ts`가 이를 강제합니다.

## 방의 물리적 구조

| 항목              | 값                            |
| ----------------- | ----------------------------- |
| 방 안쪽 영역      | 416 × 208 (좌 32, 상 32 시작) |
| 벽 두께           | 16                            |
| 문간 폭           | 48                            |
| 문 전환 판정 깊이 | 10 (문간 바깥쪽)              |
| 통과 기준 깊이    | 8 (벽 두께의 절반)            |

### 문간 기하 (DoorwayGeometry)

문간·벽 조각·전환 판정 영역을 **한 곳에서 계산**합니다. 문간 양옆 벽 조각 둘과 문간을
합치면 원래 벽 전체와 정확히 일치합니다. 통과 판정은 **플레이어의 물리 몸 중심**을
기준으로 하므로 상·하·좌·우 네 방향의 통과 폭이 똑같습니다.

`RoomBoundary.clampToRoomBounds`는 **열린 문간에서만** 플레이어가 벽 띠 안으로 들어갈 수
있게 합니다 — 닫힌 문에서는 벽처럼 막힙니다.

## 방 입장 안전 처리

방금 들어온 순간 맞아 죽는 것을 막기 위한 장치들입니다.

| 항목                      |    값 | 무엇을 막나                            |
| ------------------------- | ----: | -------------------------------------- |
| 플레이어 보호 시간        | 600ms | 입장 직후 피격                         |
| 적 AI 대기                | 400ms | 입장 순간 적이 달려듦                  |
| 출입구 안전 반경          |  72px | 문 바로 앞에 적이 스폰되는 것          |
| 방 클리어 후 문 개방 지연 | 500ms | 문 앞에서 곧바로 다음 방으로 튕겨 나감 |
| 문 통과 쿨다운            | 280ms | 방 사이를 왕복 튕김                    |

## 나무 상자 (파괴 가능 장애물)

| 항목      | 값                                    |
| --------- | ------------------------------------- |
| 체력      | 3                                     |
| 표시 배율 | 0.8 (40×40 텍스처 기준)               |
| 충돌 범위 | 29 × 27                               |
| 파괴 방법 | 씨앗·차징 빔 3회, 또는 폭탄 즉시 파괴 |
| 코인 드랍 | 20% 확률 (그중 15%는 5코인)           |

이동과 씨앗을 모두 막습니다. **충돌 범위는 그림보다 크면 안 됩니다** — 보이지 않는
벽에 걸리는 느낌이 나기 때문에, 실제 그려진 크기에 맞춰 직접 지정했습니다
(정적 바디는 setScale을 따라가지 않습니다).

## 방 상태 저장 (RoomNode)

방마다 아래 정보가 남아 있어, 나갔다 돌아와도 그대로 복원됩니다.

| 필드                                 | 무엇                                  |
| ------------------------------------ | ------------------------------------- |
| cleared / discovered                 | 클리어·발견 여부 (미니맵 표시에 사용) |
| specialRoomUnlocked                  | 열쇠로 열었는가                       |
| shopOffers                           | 상점 상품 4개와 구매·할인 상태        |
| treasureItemId / treasureClaimed     | 보물방 아이템과 획득 여부             |
| bossRewardItemId / bossRewardClaimed | 보스 보상                             |
| combatItemReward*                    | 전투방 아이템 보상 추첨·획득 여부     |
| championRolled                       | 챔피언 추첨을 이미 했는가             |
| obstacleHealth                       | 상자별 남은 체력                      |
| shopNpcBlast                         | 폭파된 상인의 바닥 자국 위치·방향     |
| pendingReward / droppedRewards       | 줍지 않은 보상의 종류·상태·위치       |
| plantedBombs                         | 심어 둔 폭탄의 자리                   |

> **함정 기록**: 폭탄은 **터질 때 목록에서 지워야** 합니다. 안 지우면 방에 들어올
> 때마다 되살아나 무한히 늘어납니다 (테스트로 고정됨).
