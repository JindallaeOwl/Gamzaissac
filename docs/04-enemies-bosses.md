### 층 배율 (BaseEnemy)

```
층 배율 = 1 + (층 - 1) × 0.16
```

체력과 점수에 곱해집니다. 1층 1.0배 → 8층 **2.12배**.
사수의 탄속에는 이 배율의 35%만 반영되고, 소환사의 **이동 속도에는 곱하지 않습니다**
(정의에 적힌 값과 실제 값이 달라지면 수치를 믿을 수 없기 때문 — 느리면
`enemies.ts`의 `speed`를 직접 올립니다).

### 증원 규칙 (EnemyReinforcementRules)

전투방은 템플릿이 깐 적 위에 **추가로** 적을 배치합니다.

```
증원 수 = max(1, min(4, floor((층 - 1) × 0.8)))   ← 2층부터
```

**방당 상한은 배치 출처와 무관하게 방 전체 기준**입니다. 템플릿이 소환사 1마리를 이미
깔았으면 증원은 둘째를 뽑지 않습니다 (`alreadyPresent`).

## 챔피언 적 (ChampionRules)

전투방에 가끔 금색으로 빛나는 크고 단단한 적이 하나 섞입니다.
"저놈부터 잡을까, 마지막으로 미룰까"라는 전투 중 판단을 만드는 것이 목적입니다.

| 항목      | 값                                       |
| --------- | ---------------------------------------- |
| 등장 확률 | 전투방당 22%                             |
| 등장 층   | 2층부터 (1층은 조작을 익히는 층)         |
| 체력 배율 | ×2.2                                     |
| 점수 배율 | ×3                                       |
| 크기 배율 | ×1.22 (판정도 함께 커짐 — 의도된 공정함) |
| 처치 보상 | 죽은 자리에 **보물 상자 확정**           |

방당 최대 1마리이며 **방당 한 번만 추첨**합니다 (`RoomNode.championRolled`) — 재입장으로
상자를 반복 획득할 수 없습니다. 보스방은 추첨하지 않고, 분열 새끼·소환 하수인·콘솔로
부른 적은 승격 경로 밖이라 자연 제외됩니다.

## 중간보스 4종 (I층)

넷 다 체력 절반에서 각성(2페이즈)해 탄이 늘고 주기가 짧아집니다. 수치는 전부
`MINIBOSS_TUNING` 한 곳에 모여 있습니다.

| 보스            |  층 | 체력 | 서명 패턴                                                                                           |
| --------------- | --: | ---: | --------------------------------------------------------------------------------------------------- |
| 뿌리 옹이       | 1층 |   46 | **거리로 두 패턴 선택** — 가까우면 방사형 뿌리탄 8발, 96px보다 멀면 도약 내리찍기 + 착지 충격탄 6발 |
| 꿈틀대는 덩어리 | 3층 |   50 | 예고 후 꿈틀 돌진, 각성 시 새끼 뱉기 (죽을 때 4마리 분열은 별개)                                    |
| 파리 여왕       | 5층 |   56 | 사격이 3발 부채꼴(각성 시 5발) + 파리 소환                                                          |
| 가시넝쿨 뭉치   | 7층 |   60 | 돌진이 끝난 자리에서 가시 6발 방사(각성 시 10발)                                                    |

> **왜 도약을 더했나**: 뿌리 옹이가 방사탄만 쏘던 시절에는 "멀리 있으면 안전"이라
> 너무 쉬웠습니다. 어느 거리도 안전하지 않게 만드는 것이 목적입니다.

> **밸런스 주의**: 체력 46~60은 패턴이 없던 시절 기준으로 올린 값입니다. 패턴이 붙은
> 지금은 다시 내려야 할 수 있습니다 (직접 플레이로 판단).

## 스테이지 보스 4종 (II층)

전부 **전용 AI 클래스**를 가지며, 체력 절반에서 2페이즈로 넘어갑니다.
체력은 "그 층의 평균 빌드 화력으로 22~38초"를 목표로 역산했습니다.

| 보스               |  층 | 체력 | 목표 시간 | 패턴                                                               |
| ------------------ | --: | ---: | --------: | ------------------------------------------------------------------ |
| 썩은 뿌리핵        | 2층 |   80 |   약 22초 | 십자탄 · 장막 · 원형탄 (탄막형, 예고 → 발사 상태머신)              |
| 늙은 지렁이 왕     | 4층 |  100 |   약 26초 | 꿈틀 돌진 · 땅굴 잠수 후 충격 링 · 새끼 소환 · 2페이즈 "허물 벗기" |
| 퇴비 파수꾼        | 6층 |  125 |   약 30초 | 탄환 버스트 5발 · 돌진, 2페이즈에서 방사탄 8발 추가                |
| 녹슨 쇠스랑의 농부 | 8층 |  165 |   약 38초 | **최종 보스**. 1페이즈 5패턴, 2페이즈 "광란"에서 2패턴 추가        |

### 최종 보스 패턴 상세

1페이즈: 삼지창 찌르기(3발 나란히) · 갈퀴 스윕(130도 부채꼴) · 씨앗 흩뿌리기(안전 틈 있는
깨진 링 12발) · 발 구르기(꽉 찬 링 14발) · 쇠스랑 근접 휘두르기(150도, 반경 62px)

2페이즈 "광란": 건초 커튼(안전 레인 1개 있는 탄 벽) · 회전 낫 부메랑(나갔다 돌아오며
두 번 위협) 추가. 쿨다운 ×0.65, 탄속 ×1.2

**근접 휘두르기와 부메랑은 탄환이 아니라 직접 피해**라 공통 피격 피드백에 따로
연결되어 있습니다.

| 확대된 적의 실제 반경 | `effectiveBodyRadius` (`EnemyScaleRules`) |

### 소환 시스템 메모

`SummonOwnershipIndex`가 소환사별로 하수인을 추적해 **각자 개인 상한을 따로** 씁니다.
하수인 쪽 역방향 색인으로 세기 때문에 소환사가 죽어도 남은 하수인이 방 전체 상한을
계속 차지합니다. 방 전체 상한 4는 **일반 전투방에만** 적용됩니다 — 지렁이 왕은 새끼
5마리를 유지하도록 맞춰져 있어 보스방에 적용하면 조용히 약해집니다.
