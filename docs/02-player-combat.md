## 공격 프로필 — 이 게임에서 제일 중요한 구조

플레이어의 "어떻게 쏘는가"는 `PlayerAttackProfile`이라는 **속성 묶음 하나**로 표현됩니다.
아이템은 이 속성들을 고치기만 하고, 전투 코드는 아이템 이름을 전혀 모릅니다.

| 속성                     | 무엇을 바꾸나                     | 예시 아이템         |
| ------------------------ | --------------------------------- | ------------------- |
| `seedCount`              | 한 번에 나가는 씨앗 수 (1~12)     | 쿼드샷, 쌍둥이 씨앗 |
| `spreadStepDegrees`      | 부채꼴이 벌어지는 각도            | 쿼드샷              |
| `overflowPenetration`    | 초과 피해로 적을 관통             | 메가씨드, 송곳      |
| `seedScale`              | 씨앗 판정 크기 (0.6~2.4)          | 메가씨드, 굵은 자갈 |
| `forceRedSeeds`          | 씨앗이 붉게 변함                  | 이쑤시개            |
| `extraForeheadEyeCount`  | 이마에 눈이 추가로 보임 (0~6)     | 쿼드샷              |
| `hasToothpickCosmetic`   | 이쑤시개가 외형에 표시            | 이쑤시개            |
| `beamChargeMsMultiplier` | 빔 차징 시간 배율 (작을수록 빠름) | 프리즘 배열 시너지  |
| `rearFire`               | 앞 부채꼴 전체를 뒤로도 복사      | 뒷주머니 씨앗       |
| `waveDegrees`            | 물결 궤적 진폭 (0~60도)           | 물결 씨앗           |
| `burstCount`             | 한 입력당 연속 발사 수 (1~5)      | 삼연발 꼬투리       |

### 왜 이렇게 만들었나

각 속성이 **"직전 단계의 전체 결과"에 적용**되게 설계했기 때문에, 새 속성 하나를
추가하면 기존 아이템 전부와 자동으로 곱해집니다.

- 물결 + 쿼드샷 = 엇갈려 물결치는 4발
- 뒷주머니 + 쿼드샷 = 앞 4갈래 + 뒤 4갈래
- 뒷주머니 + 메가씨드 = 앞뒤로 나가는 거탄

조합표를 하나씩 손으로 적을 필요가 없다는 뜻입니다. 자세한 원칙은
[03. 아이템과 시너지](03-items-synergies.md)의 "아이템 추가 원칙"에 있습니다.

### 발사 경로는 하나뿐

씨앗은 **반드시** `Player.fireSeedShot` → `Player.spawnSeedFan`을 거칩니다.
다른 곳에서 `Bullet.spawn`을 직접 부르면 그 발사만 조합에서 빠지게 됩니다.

### 세부 규칙 몇 가지

- **사격 방향 우선순위**: 여러 방향키를 동시에 누르면 위 → 아래 → 왼쪽 → 오른쪽 순으로
  먼저 걸리는 것이 이깁니다 (`selectFireDirection`)
- **점사 쿨다운**: 발수만큼 선불로 빼지 않고 **실제로 쏜 발마다 쌓습니다.** 그래서
  점사를 중간에 끊어도 손해가 없습니다. 점사 간격 상한은 85ms이며, 연사가 그보다
  빠르면 연사 쪽을 따릅니다 (고연사 빌드를 점사가 늦추지 않게)
- **씨앗 표시 크기**: 공격력이 오르면 씨앗이 **보기에만** 커집니다. 판정 크기는
  아이템이 명시한 `seedScale`만 따릅니다 — 공격력 아이템이 몰래 히트박스를 키우는
  일이 없게 하려는 것
