## 전투방 클리어 보상 (`RewardSystem.rollRoomClearReward`)

굴리는 방법:

```
값 = random() + random() × 행운 × 0.1      (행운은 0~10으로 제한)
```

| 값의 범위   | 결과                    |
| ----------- | ----------------------- |
| 0.00 ~ 0.30 | 없음                    |
| 0.30 ~ 0.45 | 코인 (그중 15%는 5코인) |
| 0.45 ~ 0.60 | 하트 1칸                |
| 0.60 ~ 0.80 | 열쇠 1개                |
| 0.80 ~ 0.95 | 폭탄 1개                |
| 0.95 이상   | **보물 상자**           |

행운이 높으면 값이 커져서 뒤쪽(좋은 보상)으로 밀립니다.

### 보물 상자를 열면 (`rollChestResult`)

| 결과   | 확률                            | 내용                            |
| ------ | ------------------------------- | ------------------------------- |
| 회복   | `min(0.58, 0.22 + 행운 × 0.03)` | 하트 반 칸                      |
| 소모품 | 나머지                          | 코인 4-10 / 열쇠 1-2 / 폭탄 1-2 |

소모품 종류는 가중치로 뽑습니다 (열쇠 20 : 코인 15 : 폭탄 15).

### 전투방 아이템 보상 (별도)

방 클리어 보상과 **따로** 굴립니다.

| 항목      | 값                         |
| --------- | -------------------------- |
| 기본 확률 | 7%                         |
| 행운 보정 | 행운 1당 +1%               |
| 상한      | 14%                        |
| 나오는 것 | **순수 능력치형 아이템만** |

거동을 바꾸는 아이템(쿼드샷·물결 등)은 보물방·상점에서만 나옵니다 →
[03. 아이템과 시너지](03-items-synergies.md)

### 기타 드랍 (`REWARD_DROP_TUNING`)

| 상황                      | 확률                   |
| ------------------------- | ---------------------- |
| 나무 상자 파괴 시 코인    | 20% (그중 15%가 5코인) |
| 상인을 폭탄으로 날렸을 때 | 50%로 5코인            |
| 챔피언 처치               | **100% 보물 상자**     |

> 상인은 방당 한 명뿐이라 폭파 코인을 반복해서 얻을 수 없습니다.
> 대신 그 방의 상점 이용을 포기하는 것이 대가입니다.

## 상점 (`ShopSystem`)

### 상품 구성 — 매번 4칸

| 칸  | 무엇                                                    |
| --- | ------------------------------------------------------- |
| 2칸 | 랜덤 패시브 아이템 (아직 최대 중첩에 안 닿은 것 중에서) |
| 1칸 | 하트 회복 (1칸 회복, 5코인)                             |
| 1칸 | 소모품 — 열쇠 또는 폭탄 (5코인)                         |

네 상품의 순서는 섞이고, **30% 확률로 그중 한 칸이 반값**이 됩니다
(최소 1코인). 개발자 콘솔의 `sale` 명령으로 강제 할인시킬 수 있습니다.

### 아이템 가격 (희귀도별)

| 희귀도    | 가격 |
| --------- | ---: |
| common    |   12 |
| uncommon  |   16 |
| rare      |   22 |
| legendary |   30 |

### 구매 조작

상품 가까이(반경 44px)에서 `F` 키 — 터치에서는 근처에 갔을 때만 나타나는 구매 버튼.

### 구매가 거절되는 경우

| 상황                 | 결과                  |
| -------------------- | --------------------- |
| 이미 팔림            | 안내만 표시           |
| 코인 부족            | 필요한 가격을 알려 줌 |
| 체력이 가득한데 하트 | 거절 (코인 안 나감)   |
| 소모품이 99개        | 거절                  |
| 아이템 중첩 한도     | 거절                  |

## 보물방

중앙에 아이템 1개가 생깁니다. 보물방 전용 드랍 테이블은 **common을 아예 뽑지 않고**
uncommon 48 / rare 37 / legendary 15로 굴립니다 — 열쇠를 쓸 값어치가 있게 하려는 것.

## 밀 수 있는 물체

| 물체        | 밀 수 있는 조건           |
| ----------- | ------------------------- |
| 하트        | 체력이 가득 찼을 때       |
| 보물 상자   | 항상                      |
| 설치된 폭탄 | 플레이어가 24px 벗어난 뒤 |

셋은 각각 미끄러지는 정도가 다릅니다. 상자는 약 7px로 "툭" 밀리고, 폭탄은 얼음처럼
관성이 남아 24~46px 미끄러집니다.

> **함정 기록**: Phaser 물리 그룹은 자식을 추가하는 순간 바디에 그룹 기본값을
> 덮어씁니다. 감속·반발·속도 상한은 생성자가 아니라 **그룹 설정이나
> `createCallback`으로** 줘야 합니다. 생성자에 쓰면 조용히 0이 되어 물체가 벽까지
> 등속으로 미끄러집니다.
